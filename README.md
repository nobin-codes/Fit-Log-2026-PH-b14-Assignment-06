# 🏋️ FITLOG

> **Train with intent. Log every set.**

FitLog is a responsive workout library and planning application that helps users explore workouts, view detailed exercise information, build a daily workout plan, and save exercises for later.

---

## 🛠️ Technologies Used

**Next.js** · **React** · **TypeScript** · **Tailwind CSS** · **REST API** · **React Context API** · **LocalStorage**

---

## ✨ Key Features

| # | Feature | Description |
|---|---|---|
| **01** | 📚 **Workout Library** | Browse workouts with muscle groups, equipment, duration, calories, and ratings. |
| **02** | 🔎 **Workout Details** | View descriptions, difficulty, sets, reps, specifications, and instructions. |
| **03** | 📝 **Today's Plan** | Add workouts to today's plan and manage selected exercises. |
| **04** | 💾 **Save for Later** | Save workouts and access them from the Saved section. |
| **05** | ↕️ **Workout Sorting** | Sort workouts by Duration, Calories, or Rating. |
