🏋️ FITLOG
Train with intent. Log every set.

FitLog is a responsive workout library and planning application that helps users explore workouts, view detailed exercise information, build a daily workout plan, and save exercises for later.

🛠️ Technologies Used
Technology	Usage
Next.js	Application framework and routing
React	User interface development
TypeScript	Type-safe development
Tailwind CSS	Styling and responsive design
REST API	Workout data
React Context API	Plan and saved workout state management
LocalStorage	Persisting plan and saved workout data
✨ Key Features
01 — 📚 Workout Library

Browse a collection of workouts with images, muscle groups, equipment, duration, calories, and ratings.

02 — 🔎 Workout Details

View complete workout information including description, difficulty, sets, reps, specifications, and step-by-step instructions.

03 — 📝 Today's Plan

Add workouts to today's plan and manage your selected exercises from one place.

04 — 💾 Save for Later

Save workouts for later and access them from the Saved section of My Plan.

05 — ↕️ Workout Sorting

Sort the workout library by Duration, Calories, or Rating.
